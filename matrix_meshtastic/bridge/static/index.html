Gerät bestätigen

Geräte und Raumschlüssel verwalten
  1. Für eine zusätzliche, optionale Gerätebestätigung dieses Konto auch in Element oder deinem bisherigen Matrix-Client öffnen.
  2. Das gewünschte Gerät unten auswählen und die Symbole auf beiden Geräten vergleichen.
  3. Für ältere Nachrichten bei Bedarf eine verschlüsselte Schlüsseldatei importieren. Die Ende-zu-Ende-Verschlüsselung funktioniert unabhängig von der zusätzlichen Gerätebestätigung.

Eine Fingerabdruckfreigabe gilt nur in dieser App. Wenn Element diese sendende Sitzung als unbestätigt anzeigt, muss sie auch dort bestätigt werden. Ein Schlüsselimport bestätigt keine Geräte.

Schlüssel importieren

In Element unter Sicherheit die Raumschlüssel als verschlüsselte Datei exportieren. Hier die Datei und das beim Export gewählte Passwort verwenden. Ein Wiederherstellungsschlüssel oder das Matrix-Anmeldepasswort ersetzt diese Exportdatei nicht. Der Import funktioniert unabhängig von einer Gerätebestätigung.
